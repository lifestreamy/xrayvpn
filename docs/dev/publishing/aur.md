# AUR

The `xrayvpn-bin` package in the [Arch User Repository](https://aur.archlinux.org/): the release
binary plus a desktop entry and an icon.

## Artifact

Rendered from `packaging/aur/`:

- `PKGBUILD` — `pkgname=xrayvpn-bin`, `arch=('x86_64')`, sources: the `linux-x64` portable asset
  from the release and the `LICENSE` of the tag; `options=('!strip' '!debug')` keeps the onefile
  binary intact;
- `.SRCINFO` — generated by `makepkg --printsrcinfo`;
- `xrayvpn.desktop` and `xrayvpn.png` — the same desktop entry and 256 px icon as in the .deb
  build.

## Pipeline

`publish-aur.yml` runs on `ubuntu-24.04` in the `aur` environment:

1. checks that the tag is a plain `vX.Y.Z` and the latest published release, then downloads
   `SHA256SUMS.txt` and the `LICENSE` of the tag;
2. renders the set with `scripts/cd/render_channels.py --license ...`;
3. generates `.SRCINFO` with `scripts/cd/arch_container.sh srcinfo` in an `archlinux` container as a
   non-root builder (makepkg refuses to run as root);
4. keeps the set as the `aur-package` build artifact;
5. pushes over SSH to `ssh://aur@aur.archlinux.org/xrayvpn-bin.git`, branch `master`, with the
   commit message `upgpkg: xrayvpn-bin <version>-1`; the host key comes from the pinned
   `.github/ssh/known_hosts`.

Secret: `AUR_SSH_PRIVATE_KEY`. The first push creates the package if the name is free; the initial
commit must contain `PKGBUILD` and `.SRCINFO`, which this pipeline guarantees.

## Registration

The Arch team pauses new account registration when automated sign-ups get out of hand: it happened
on June 15 – July 13, 2026 (after the malicious-package incident) and again in September 2026. The
pause affects only new accounts: existing packages and pushes keep working, there is no manual
queue, and retrying the page tells nothing sooner than `aur-general` and the Arch news feed do.
When registration reopens, run this pipeline for the release that is current at that moment.

## Repair

Re-run the pipeline with the released tag and approve it. Local fallback:

```
git clone ssh://aur@aur.archlinux.org/xrayvpn-bin.git
makepkg --printsrcinfo > .SRCINFO
git add PKGBUILD .SRCINFO xrayvpn.desktop xrayvpn.png
git commit -m "upgpkg: xrayvpn-bin <version>-1"
git push
```

## Verify and remove

```
yay -S xrayvpn-bin
xrayvpn --version
```

The weekly `verify-channels` run builds and installs the package with
`scripts/cd/arch_container.sh install` in an `archlinux` container and asserts that the installed
version equals the latest release. Removal: use the package's "Submit Request" action on the AUR
website to file a deletion request; a trusted user processes it.
