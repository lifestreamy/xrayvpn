# Что запланировано, что в работе, что уже сделано

Сроки примерные, не обещания. Порядок может меняться.

## Сделано в v0.4.1 (2026-09-12)

- Standalone-сборки в Releases (Windows x64, Linux x64/arm64, macOS arm64): встроенные
  роли+плейбуки, стабильный кэш распаковки запусков, двойной клик на Windows открывает консольного
  помощника; сборка и дымовые проверки — CI-матрицей четырёх платформ.
- Python-установка без клона: колесо возит payload внутри; дистрибутив называется `xrayvpn`.
- Консольная сессия (REPL) при запуске без аргументов; `deploy --help` показывает фактические
  дефолты из `config/settings.yml` и примеры; ответ смены языка — одной строкой.
- Анти-hairpin: IP сервера закреплён правилом DIRECT в генерируемых Clash/Mihomo-профилях.
- Уведомление о новых версиях в бинарных сборках (раз в сутки, молча при сбоях) + манифест
  `latest.json` и `SHA256SUMS.txt` у релиза.
- Полностью русский интерфейс (`--ru` / `XRAYVPN_LANG`), `.pyw`-лаунчеры двойного клика,
  guard малой памяти (предложение swap-файла 1 ГБ по явному согласию), `ufw` ставит только
  allow-правило, `podman` удалён, дефолт `--execution remote`, проброс ключевых флагов в
  bash/PowerShell-обёртки, `uv tool install --editable python-client` для голой `xrayvpn` в PATH.
- CI: тесты клиента на Windows/macOS/Ubuntu и релизная матрица standalone-сборок четырёх платформ; фиксированный
  uv.
- Релизная политика: трёхзначные версии, один релиз на версию, критерии выхода без календарного
  ожидания (CI-покрытие клиентских сценариев + ручная проверка по шпаргалке); plain-тег `vX.Y.Z` —
  релиз (канал «Latest»), `_experimental` — опциональный pre-release-маркер, fix-forward.
- Контактные ссылки автора переведены на korelov.dev.

## Сделано в v0.3 (2026-09-05)

- Вся конфигурация роли (набора файлов установки Xray на сервере) — в одном файле `config/settings.yml`.
- Основной CLI-клиент `xrayvpn` (Python): удалённый режим по SSH и локальный режим; параметры —
  флагами, файлы руками править не нужно.
- CI на GitHub Actions: molecule-матрица ubuntu 22.04 / 24.04 / debian 12 плюс полный хост-прогон
  с e2e через mihomo-клиент (ufw проверяется там).
- Варианты рантайма: `native` (по умолчанию), `docker`. Контейнерные systemd-юниты
  работают в `--network host`.
- `xray.service` включается при развёртывании; `python3-venv` и `ufw` авто-устанавливались где нужно
  (поведение `ufw` изменено в v0.4.1).
- Понятные ошибки по `inventory.yml` и подсказка, как создать файл из шаблона.
- Релизная политика (`docs/dev/RELEASE.md`), CHANGELOG (RU/EN), чистка доков под один ритм.
