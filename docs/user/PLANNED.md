# Планы

Что появится дальше. Порядок может меняться.

- **Визуальный клиент.** Мастер развёртывания и повседневные команды в одном меню: деплой,
  статус, логи, ротация. Русский и английский интерфейс.
- **Статус и восстановление.** Состояние сервиса, последние логи и перезапуск из клиента.
- **WARP.** Несколько исходящих и смена точки подключения.
