# Проверка VPS перед оплатой

Мне везло с серверами, но вам может не повезти. Прежде чем платить за VPS на долгий срок, возьмите
самый дешёвый тестовый тариф и прогоните короткий чек-лист ниже. Смысл простой: убедиться, что
сервер вам отвечает — пинги идут, порты открыты, DNS работает, нужных вам сайтов по TLS не
режут.

## Что проверять

- **ICMP** — базовая связность: пинг из вашего региона < 100 мс.
- **TCP 443** — порт должен слушаться: на нём встанет REALITY.
- **DNS** — резолв популярных доменов (`google.com`, `youtube.com`, `github.com`).
- **Цензура по SNI** — REALITY маскируется под легитимный сайт; если цензор режет TLS-рукопожатия
  к популярным доменам по SNI, REALITY будет работать плохо. Это самая трудная для проверки часть.

## Что должно быть ОК перед оплатой

- Пинг до VPS < 100 мс (или сколько нормально для вашего региона).
- TCP 443 открыт.
- DNS работает (например, `dig google.com @8.8.8.8` с VPS).
- Нет блокировок по SNI к популярным доменам — для REALITY критично.

## Команды

Подключитесь к VPS по SSH после покупки тестового тарифа и выполните:

```bash
ping -c 4 <VPS_IP>                  # базовая связность (c вашей машины)
nc -zv <VPS_IP> 443                 # TLS/HTTPS порт (с VPS слушать, с вашей машины проверять)
curl -4 https://ifconfig.io         # после развёртывания и подключения клиента — внешний IP
```

Ожидаемый результат:

- `ping` — 4 пакета отправлено и принято, `0% packet loss`, время в миллисекундах (например
  `time=25.3 ms`). Потери выше нуля или > 150 мс — сервер далеко или перегружен.
- `nc -zv <VPS_IP> 443` — `succeeded!`; `Connection refused` — порт закрыт или никто не слушает,
  разбираться до оплаты.
- `curl -4 https://ifconfig.io` — до VPN покажет IP дата-центра; после подключения клиента без
  WARP — IP VPS; с WARP — IP Cloudflare.

Первые две проверки — до развёртывания, последняя — после.

## Предупреждение

Ручной набор не вылавливает тонкие системы DPI — они умеют резать SNI избирательно, и заметить это
простыми командами нельзя. Если регион с жёсткой цензурой — закладывайте риск: проверить
полностью можно только реальным трафиком уже после оплаты.
