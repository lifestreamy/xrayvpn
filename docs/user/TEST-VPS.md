# Проверка VPS перед оплатой

Мне везёт с серверами, но не факт, что повезёт и вам. Поэтому чтобы не переплачивать за сервер, который потом не подойдёт для развёртывания VPN, проверьте в самом дешёвом тестовом режиме моменты из чек-листа ниже.

То есть желательно перед развёртыванием убедиться, что сервер устраивает: что пинги проходят, порты открыты, DNS работает, нет блокировок нужных вам сайтов по SNI.

## Что проверять на VPS

- **ICMP** — базовая связность. Пинг < 100 ms из вашего региона.
- **TCP 443** — порт должен быть открыт. REALITY требует, чтобы клиент мог достучаться до вашего сервера по этому порту.
- **DNS** — резолв популярных доменов (`google.com`, `youtube.com`, `github.com`).
- **Цензура через SNI** — REALITY маскируется под легитимный сайт. Если вдруг некий цензор режет TLS-рукопожатие по SNI к популярным доменам, REALITY может работать плохо. Это сложнее проверить без специализированных скриптов.

## Готовые инструменты

Ниже — внешние проекты, которые я не встраиваю в репозиторий. Скачайте и запустите отдельно.

### `AiCarrox/carrox-vps-check`

Единый bash-скрипт, ~5 минут на полный прогон. Покрывает 14 пунктов: виртуализация, сеть, IP, диск, маршрутизация, разблокировки стриминга.

GitHub: https://github.com/AiCarrox/carrox-vps-check

Годится для общей проверки VPS.

### `dy0422/ipcheck-plus`

IP quality + разблокировки стриминга и AI-сервисов. Полезен, если вы хотите знать, как VPS выглядит для внешних сервисов.

GitHub: https://github.com/dy0422/ipcheck-plus

## Что должно быть ОК перед оплатой

- Пинг до VPS < 100 ms (или сколько обычно в вашем регионе).
- TCP 443 открыт.
- DNS работает (например, `dig google.com @8.8.8.8` через VPS).
- Нет DPI на SNI к популярным доменам (для REALITY критично).

## Ручные команды

Если не хотите запускать автоматические скрипты, минимальная проверка:

```bash
ping -c 4 <VPS_IP>                  # базовая связность
nc -zv <VPS_IP> 443                # TLS/HTTPS порт (REALITY будет слушать здесь)
curl -4 https://ifconfig.io        # после развёртывания VPN — внешний IP клиента
```

Ожидаемые результаты команд (примерные):

- `ping` — 4 пакета отправлено и получено, `0% packet loss`, время ответа в миллисекундах (например, `time=25.3 ms`). Если потерь больше нуля или время > 150 ms — сервер далеко или перегружен.
- `nc -zv <VPS_IP> 443` — `succeeded!` — порт открыт. `Connection refused` — порт закрыт или ничего не слушает, разбираться до оплаты.
- `curl -4 https://ifconfig.io` — покажет внешний IP:
  - VPN выключен — IP вашего провайдера;
  - VPN включён без WARP — IP вашего VPS;
  - VPN включён с WARP — IP Cloudflare.

Первые две — до развёртывания. Третья — после подключения через VPN-клиент.

## Предупреждение

Ручная проверка не покрывает специализированные DPI-системы. Если вы знаете, что в вашем регионе жёсткая цензура — используйте `carrox-vps-check` или аналогичный скрипт перед долгосрочной оплатой. Таких инструментов мало, и они устаревают быстрее, чем обновляются системы фильтрации.
