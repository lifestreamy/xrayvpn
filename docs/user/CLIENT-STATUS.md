## Заметки

- **Clash Verge** — мой основной на Windows 11. Импортируете `clash_client_*.yaml` — и работает.
- **FlClash** — мой основной на Android. Тот же YAML-конфиг.
- **Amnezia** — первый клиент, для которого этот проект генерировал конфиги. Подключается, но есть известные проблемы: на Windows split-tunnel может обрушить сетевой стек, на Android нестабильны keepalive и фоновая работа. Предпочитайте Clash Verge или FlClash, если вам не нужен именно Amnezia.
