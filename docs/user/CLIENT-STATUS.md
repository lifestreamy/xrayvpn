## Заметки

- **Clash Verge** — мой основной на Windows 11. Импортируете `clash_client_*.yaml`.
- **FlClash** — мой основной на Android. Тот же YAML-конфиг.
- **Amnezia** — первый клиент, для которого этот проект генерировал конфиги. Подключается, но есть проблемы: на Windows split-tunnel может обрушить сетевой стек, на Android нестабильны keepalive и фоновая работа. Лучше Clash Verge или FlClash, если вам по какой-то причине не нужен именно Amnezia.
