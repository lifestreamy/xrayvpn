# Иконки xrayvpn

## Структура

```
assets/icon/
├── master/                     # исходники (Source of Truth)
│   ├── xrayvpn-icon-master-main.png    # РАСТРОВЫЙ SoT: 3072×3072, 8-bit RGBA
│   ├── xrayvpn-icon-master-main.svg    # дизайн-источник (для человека/редактора)
│   ├── xrayvpn-icon-master-main.webp   # web-дериватив
│   └── thin_border/            # АРХИВ: вариант с тонкой границей, в сборке не участвует
├── windows/
│   └── xrayvpn.ico             # производное: мульти-размерный ICO для сборок Windows
├── icon-preview.png            # производное: 256×256 для README
└── icon-preview.html           # производное: приёмочная таблица 16/32/48/256 на светлом и тёмном фоне
```

## Роли форматов

- **PNG (master)** — единственный растровый Source of Truth. Все производные файлы
  генерируются из него; ручная правка производных запрещена — правьте мастер и
  перегенерируйте.
- **SVG (master)** — векторный дизайн-источник для редактирования человеком;
  в автоматической сборке не используется (генератор SVG не растеризует).
- **WebP (master)** — компактный дериватив для web-страниц.

## Генератор

```bash
python scripts/make_icon.py            # из мастера по умолчанию
python scripts/make_icon.py --master path/to/other.png
```

stdlib-only. Пайплайн: точный area-average даунскейл 3072 → {16, 24, 32, 48, 64,
128, 256} (32-bit RGBA, round-to-nearest), для 16 и 24 px — детерминированный
despeckle (модальный фильтр 3×3). Без квантования в палитру. ICO содержит весь
набор размеров, каждый кадр PNG-сжат (256 px — обязательно PNG).

## Производные файлы

| Файл | Потребитель |
|---|---|
| `windows/xrayvpn.ico` | сборщики бинарников (Nuitka / PyInstaller) через `python-client/build_support.py` (`ICON_ICO`) |
| `icon-preview.png` | иллюстрация в документации |
| `icon-preview.html` | визуальная приёмка размеров на светлом/тёмном фоне |

Байт-страж: `python-client/tests/test_make_icon.py` проверяет, что закоммиченные
ICO и preview байт-в-байт совпадают с регенерацией из мастера. После изменения
мастера запустите генератор и закоммитьте обновлённые производные файлы.
