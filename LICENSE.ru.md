# Лицензия (краткое описание на русском)

Это **юридически не обязывающее** описание на понятном языке. Полный текст лицензии см. в файле [LICENSE](LICENSE) (английский — единственная юридически обязывающая версия).

## Что можно

- Использовать проект **лично** — поставить себе VPN на свой VPS, подключаться со своих устройств.
- Использовать для **семьи и близкого круга** — поднять VPN для себя и родных.
- **Изучать** код, переделывать под себя (модификации для личного использования).
- **Распространять** некоммерчески, например дать другу файл конфига или помочь ему развернуть по инструкции.

## Что нельзя

- **Продавать** проект, его части или производные.
- Использовать в **платном сервисе** — продавать «VPN как услугу», монетизировать, делать managed-VPN для клиентов за деньги.
- Встраивать в **коммерческий продукт** или устройство, которое продаётся.

## Если ты просто хочешь развернуть VPN для себя

Смело используй. Читай [README.md](README.md) / [README.en.md](README.en.md), запускай готовую сборку из [Releases](https://github.com/lifestreamy/xrayvpn/releases/latest) или обёртки `shell-clients/bash/provision-vpn.sh` / `shell-clients/powershell/Provision-VPN.ps1` — всё под лицензией разрешено.
